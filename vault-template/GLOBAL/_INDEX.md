# Global — overview

Knowledge that is true regardless of which project you are in.

- [[GLOBAL/gotchas/_INDEX|gotchas/]] — traps, grouped by technology. The highest-value folder here.
- [[GLOBAL/architecture/_INDEX|architecture/]] — cross-system contracts and shared data formats
- [[GLOBAL/insights/_INDEX|insights/]] — non-obvious things learned that are not traps
- [[GLOBAL/snippets/_INDEX|snippets/]] — reusable commands and code fragments
- [[GLOBAL/config/_INDEX|config/]] — how your own tooling is set up and operated
- [[GLOBAL/maintenance/_INDEX|maintenance/]] — output of scheduled jobs, health reports

> [!info] The ownership test
> If the project you are in were deleted tomorrow, would the note still be true? Yes → it is global.
