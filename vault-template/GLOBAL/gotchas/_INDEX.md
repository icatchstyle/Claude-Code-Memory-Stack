# Global gotchas — overview

Traps that are not specific to one project, grouped by technology.

Create one subfolder per technology: `docker/`, `git/`, `kubernetes/`, `terraform/`, `python/`, `networking/`, …

> [!warning] The callout is mandatory
> Every gotcha starts with `> [!severity] Title`. Without it the note is invisible to gotcha
> retrieval — it exists and never surfaces at the moment it would have saved you.
> Severities: `danger` (data loss, production breakage) · `warning` (the standard trap) ·
> `tip` (a better way) · `info` (prevents a wrong assumption).
