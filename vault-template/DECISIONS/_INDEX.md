# Decisions — overview

Cross-cutting ADRs: what was decided, which options were weighed, and what it costs.

Project-scoped decisions live in `PROJECTS/<project>/decisions/`.

Template: [[TEMPLATES/adr|adr.md]]

> [!tip] Write the ones you will be asked about
> The value of an ADR is answering "why is it like this?" six months later, without the person
> who decided it.
