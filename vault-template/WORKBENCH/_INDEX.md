# Workbench — overview

Dated working material: `<YYYY-MM-DD>-<topic>/`.

**Deliberately temporary.** Investigations produce a lot of material that is valuable for two
weeks and noise afterwards. Give it a dated folder and let it age out.

Prune monthly: promote the durable core into GLOBAL or PROJECTS, delete the rest.
